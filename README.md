# Portfolio

Personal site — about me, CV, and web experiments. Cinematic web + backend.

## Stack

- **Next.js** (App Router, TypeScript) — full-stack
- **Tailwind CSS** — styling
- **Framer Motion** — animation / cinematic transitions
- Backend so far: Next.js route handlers (Node/TS). API + DB experiments to follow.

## Commands

```bash
npm run dev      # dev server on :3000
npm run build    # production build
npm test         # (add tests when there is code worth testing)
```

## Layout

```
src/app/     # App Router pages and route handlers
public/      # static assets
```
